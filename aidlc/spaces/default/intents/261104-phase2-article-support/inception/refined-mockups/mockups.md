# Phase2 詳細画面案

## 入力と位置付け
`../../ideation/rough-mockups/wireframes.md`、同`user-flow.md`、`../user-stories/stories.md`、`../requirements-analysis/requirements.md`、`../practices-discovery/team-practices.md`と本段階の確認済み回答に基づく。以下は画面構成・寸法・文言を具体化する設計案であり、実装のスクリーンショットや実機合格の証拠ではない。macOS標準外観を引き継ぐ。

## M1 記事の入口・下書き選択（US1.1）
選択結果の4枚の後に「記事を作る」または「記事を再開」を置く。「記事」メニューには現在の選択に対する作成／再開と「下書きを開く…」を配置する。未確定の場合は現在選択からの作成だけを無効にして理由を示し、保存済み下書きの選択は使える。

「下書きを開く…」は最小幅480ptの選択シート。上に見出し、中央にタイトル・元アルバム名・更新日時の行、下に「キャンセル」「開く」。未選択なら開くは無効。空タイトルは「無題の記事」、同名は日時と短い記事識別情報で区別する。更新日時の新しい順、同時刻は記事識別情報で安定順序とする。0件は「保存済みの下書きはありません」。読込失敗は0件と分け「再試行」「キャンセル」。行数が多ければリストをスクロールし、制作履歴・公開状態・成果物一覧は追加しない。

同じアルバム・同じ順序の4枚の再確定では「新しく記事を作る」「既存の下書きを再開」「キャンセル」。再開候補が複数なら同じ行形式で選ぶ。旧記事の削除や自動置換はしない。入口を連打しても同じ編集対象を重複生成しない。

## M2 記事編集・1200×800ptの例（US1.2/US1.5/US1.6）
| 領域 | 寸法・配置 | 表示内容 |
|---|---|---|
| ヘッダー | 外周16pt、要素間8pt、長名は折返し | 「記事を編集」、元アルバム名、編集／プレビュー切替、保存状態 |
| 写真列 | 左幅280pt、右との間16pt | 1〜4の順序付きカード。写真はaspect fit、各画像領域最大240pt高。番号と取得状態は画像外の文字で表示 |
| 記事フォーム | 残り幅、最小400pt、縦スクロール | タイトル、導入、写真1〜4への文章、結び、撮影情報 |
| 下部操作 | 内容に応じて折返し、本文を覆わない | 「下書きを保存」「本文をコピー」「記事と画像を書き出す」「戻る」 |

本文入力は各項目の上に可視ラベルを置く。導入・各写真文・結びは初期表示高さ96pt以上の複数行入力とし、入力内容を切り捨てない。タイトルは初期候補を編集可能。撮影情報は「撮影日（候補）」と候補の確認・変更・削除、場所・機材・フィルム・人物名の自由入力。候補がなければ「日付候補なし」と手動入力操作を置く。不正日付は直下で年月日の修正を案内する。

画像なしでも番号付きプレースホルダーと「写真3を取得できません。写真アプリでダウンロードしてから再試行してください」等を表示し、文章編集は維持する。認可なし・参照なし・原因不明を判別可能な範囲で分け、判断できない原因を断定しない。

## M2N 640×560ptと境界幅の例
記事内容領域の最小640×560pt。横幅960pt以上はM2、未満は「ヘッダー → 4枚 → 本文 → 撮影情報 → 操作」の縦配置。狭幅の4枚は2列で番号順、画像全体を表示し、フォームは全幅を使う。高さは必要に応じスクロールする。ヘッダー・操作も折返し、ボタンを省略しない。キーボード移動先は画面内へスクロールし、入力中の幅変更でも文章・保存状態・選択を保持する。

検証する内容領域：640×560、959×800、960×800、961×800、1200×800pt。960ちょうどは左右配置。既存の写真選択画面の切替幅は変更しない。

## M3 プレビュー（US1.6）
ヘッダーに「プレビュー」、編集へ戻る切替、保存状態。本文幅は最大720pt、中央寄せ、左右16pt以上の余白、縦スクロール。順序はタイトル・導入・写真1/文章1〜写真4/文章4・結び・撮影メモ。画像はaspect fit。撮影メモは入力値のある項目だけ。現在の入力を表示し、未保存ならその表示を保つ。プレビューをnote上の表示保証としない。コピー・出力は下部へ置く。

## M4 未保存・保存確認（US1.2/US1.3/US1.7）
| きっかけ | シート本文・操作 |
|---|---|
| 未保存で戻る・閉じる・終了・別記事へ切替 | 「未保存の変更があります。保存してから閉じますか？」／「編集を続ける」「保存せず閉じる」「保存して閉じる」 |
| 未保存で書出し | 「書き出す前に下書きを保存してください」／「キャンセル」「保存して書き出す」 |
| 保存失敗 | 元の入力を残して「下書きを保存できませんでした」と具体的に分かる理由。「再試行」「編集を続ける」 |

保存中は同じ操作の二重開始を無効化し、進行を文字で示す。保存成功前に閉じたり書出し開始へ進めない。破棄を既定の強調操作にしない。シートを入れ子にせず、必要な次の確認は前のシートを閉じて表示する。

## M5 出力状態と受渡し（US1.4/US1.7/US1.8）
| 状態 | 内容と有効な操作 |
|---|---|
| 保存先選択 | OS標準のフォルダ選択。取消で入力保持のまま戻る |
| 実行中 | 「画像2/4を書き出しています」等。進捗バーと「キャンセル」。割合不明は不定進捗とし架空の割合を出さない |
| 成功 | 「記事と画像4枚を書き出しました」、保存先。「Finderで開く」「本文をコピー」「編集へ戻る」 |
| 失敗 | 該当写真番号・権限・容量等、分かる原因。「再試行」「保存先を選び直す」「編集へ戻る」の該当操作 |
| 取消 | 「書き出しをキャンセルしました」。一時物の片付け完了後に再試行可能。一時物削除失敗ならその案内を残す |
| Finder失敗 | 「出力フォルダを開けませんでした」と保存先。出力結果とは分けて再操作を案内 |

出力中は対象記事の編集・保存・別記事切替を無効化し、キャンセルと無関係な画面操作は応答可能にする。固定した保存内容の出力と現在の表示が違わないようにする。4枚と記事・manifestが完成するまで成功表示・完了のFinder導線を出さない。

成功結果からの「本文をコピー」は、その出力に使った固定本文をコピーする。編集へ戻った後のコピーは現在入力を使う。どの本文をコピーしたか操作領域の文脈を明確にする。

## 検証条件と範囲
名称200文字、各本文10,000文字、日本語・結合文字・絵文字・改行と連続文字で、保持・折返し・スクロール・キーボード到達を確認する。検証値は入力上限ではない。OS標準の文字拡大設定でも操作を隠さないことを確認する。成功・失敗・取消でも写真ライブラリの元データを変更しない。

VoiceOver追加設計・試験は対象外。既存の属性の削除はしない。本書は設計上の確認条件であり、実機検証の完了宣言ではない。
