# 操作性・可読性の確認項目

## 範囲と状態
`mockups.md`と`interaction-spec.md`を、`../../ideation/rough-mockups/wireframes.md`、同`user-flow.md`、`../user-stories/stories.md`、`../requirements-analysis/requirements.md`、`../practices-discovery/team-practices.md`へ対応付ける。本書のチェックは計画であり、全項目未検証。VoiceOver追加設計・試験は本人指定で対象外。WCAG全体の適合宣言はしない。

| 項目 | 合格条件・検証 | 現状 |
|---|---|---|
| キーボード | 入口・選択・全入力・切替・保存・確認・コピー・書出し・取消・再試行・Finderへ到達し実行できる | 未検証 |
| 焦点 | 見た目順、見えるリング、画面外へ移動した焦点はスクロール表示。シート取消後は起点へ戻る | 未検証 |
| 破棄 | 未保存離脱で確認し、保存失敗なら閉じず、明示破棄だけ未保存分を捨てる | 未検証 |
| 狭幅・境界 | 640×560、959/960/961×800、1200×800ptで全操作到達、960以上は左右、未満は縦 | 未検証 |
| 長文・文字 | 名称200文字、各本文10,000文字、結合文字・絵文字・改行・連続文字が保存/切替/表示で壊れない。検証値を入力上限にしない | 未検証 |
| 日付 | 候補と確認済みを区別、不正入力は修正方法と項目を示し、値を保持 | 未検証 |
| 写真 | 1〜4番号と文章対応、fitで全体表示、取得不能でも番号・理由と本文を保持 | 未検証 |
| 保存・出力状態 | 未保存/保存中/保存済み/失敗、出力進捗/成功/取消/失敗を文字で区別。色だけに依存しない | 未検証 |
| 色・文字拡大 | light/darkとOS文字設定で操作・ラベルが読める。通常文4.5:1、主要UI3:1を設計目標として実装時に測定し、標準色採用だけで合格としない | 未検証 |
| コピー | 未保存入力または当該出力本文という文脈を明示し、コピー成功で保存状態を変えない | 未検証 |
| 非変更 | 正常/失敗/取消で元写真・編集内容・アルバム・フォルダを変更しない。境界の呼出し試験と実機確認を区別 | 未検証 |

## 確認の残し方
自動UI試験は合成データの条件を明記し、本人の実写真・OSパネル・Finder・note受渡しは別に記録する。画面寸法・OS・文字条件と成功/失敗/未確認を残す。未達を理由なく基準変更で解決しない。
