# 外部依存と実行条件

Bolt（動く成果物まで仕上げる1回の実装）はB1=U1、B2=U2、B3=U3。外部API開発や他チームの納品待ちはない。次の利用環境と本人操作が実動作の前提になる。

| 依存 | 所有者 | 対象 | 待ち時間・前提 | 遅れた時の扱い |
|---|---|---|---|---|
| GitHub公開リポジトリ/Actions | 本人、実行基盤はGitHub | 全Bolt統合前 | APIでpublic確認済み、Actionsの実行は未実証。設定・push/PR後に初回試験が必要。固定所要時間は約束しない | CI成功まで未統合。ローカル成功をCIと呼ばない |
| 標準xcode-27イメージ | GitHub | 全Bolt | macOS 27/Xcode 27を提供、実行時の版を記録。本人環境27.2と完全同一とは仮定しない | SDK/GUI差を調査、対象OS・試験を黙って削らない。有料runnerへ切替えない |
| 本人のMac・写真ライブラリ・写真アクセス許可 | 本人 | B1/B3、B2利用確認 | 本人環境macOS 27.2 / Xcode27.2。必要写真は写真アプリで事前ダウンロード。アプリは通信要求しない | fixture試験を進めつつ実機は未確認と記録。画像不能でも文章を保護 |
| 保存先の選択とアクセス | 本人、OS | B1/B3 | Sandbox内の利用者選択、空容量、ジョブ中のアクセス寿命 | 取消/権限拒否/容量不足を失敗として案内、旧成果物非変更 |
| 最初の実動作確認・各承認 | 本人 | B1後、各コード計画 | 日程は本人の都合。固定締切なし | 承認・実証を推定しない。後続の必要条件を維持 |
| noteへの本文貼付け・画像手動挿入 | 本人、note UI | B3 | アプリ連携/自動投稿なし。本人が出力を手動で扱う | 未確認を完了にしない。UI差があれば手順を更新 |

## CIの実行設定と費用
`xcode-27`標準arm64 runner、PR・作業ブランチpush・手動実行。権限はcontents: read、秘密情報なし、pull_request_targetなし。本人写真や下書きをCIへ渡さず合成fixtureで各層とUIの一連の操作を試験する。実機の写真認可/現在編集/色/Sandbox/noteは別確認。各実行のOS/Xcodeとコミットを記録し、同じコミットの成功を統合条件とする。

標準runnerは公開リポジトリで実行無料。[GitHub公式](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)、[Xcode27一般提供](https://github.blog/changelog/2026-10-15-xcode-27-runner-image-generally-available/)を2026-11-04確認。大型runnerや有料追加を使わず、キャッシュ/成果物アップロードも追加しない。公開設定が変わった場合は無料条件を再確認し、課金構成へ自動移行しない。CI設定の初回導入はB1の統合前とし、後段CI Pipelineで全体整合を確認する。

## 保存・出力の技術的前提
保存形式/操作IDの永続照合、画像API/期限/メモリ、Sandboxの権限寿命はB1の各設計で確定する。一時出力確定と異常終了回復、同じjobIDの結果照合はB3の各設計で具体化する。未決定を実装済みとせず、コード生成前の設計・コード計画に解決結果を含める。
