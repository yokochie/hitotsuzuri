# 利用者

## P1 本人 — 週次の記事制作者
- 役割：本人のMacで、写真アプリから選んだ4枚をnote記事へまとめる。最優先かつ唯一の利用者像。
- 目的：写真の順序と文章の対応を保ち、下書きを保存・再開し、記事と画像を安全に手動でnoteへ移す。
- 困りごと：写真選択後の記事制作を続けやすくしたい。下書きや既存成果物を失いたくない。
- 利用環境：既存のmacOSアプリ、ローカル画像。画像取得の通信は要求しない。note側は本人が操作する。
- 判断：範囲・優先順位・受け入れの最終判断者。手動保存、再確定時の新規／再開確認を選択済み。
- 操作：キーボードと狭幅を考慮する。VoiceOverの追加設計・検証は本人指定で対象外。能力や障害等を推測しない。
