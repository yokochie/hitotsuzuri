# U3 既存記事画面への接続

画面配置と入力フォームはU2のまま利用し、新たな画面基盤を作らない。所有はcomponents.mdに従う。

| 接続部品 | 入力状態 | 利用者の操作・結果 |
|---|---|---|
| 本文コピー操作 | 現在編集とコピー状態 | 現在入力をコピー。成功/失敗を文字で示しdirtyは保つ |
| 出力前の確認 | 編集状態と保存結果 | 未保存なら保存/取消。成功した固定入力だけを後続へ渡す |
| 保存先選択 | 利用者が選んだ親とアクセス結果 | 取消で編集復帰。拒否や不在は入力を保って案内 |
| 出力進捗 | activeJobID、段階、完了枚数、取消待機 | 取消を受付後も終端を待つ。古いjob通知は表示しない |
| 完了結果 | 同jobの固定本文と完成場所 | 完了本文のコピー、Finder表示。両操作の失敗は出力成功と分離 |
| 失敗と再試行 | 分類、対象写真番号、残存の有無 | 元入力を維持し、本人が原因解消後に新IDで再出力 |
| 未完ジョブの案内 | ローカル回復記録 | 保存先再選択後に照合、対象を示した片付け、または保留 |

処理中は対象の編集・保存・切替・重複開始を保護する。操作の終端で元の出力/コピー操作へ焦点を戻す。出力中の終了は取消と収束を経て扱い、異常終了では次回の未完案内へつなぐ。狭幅・長文・キーボード到達性はU2の条件を引き継ぐ。本人向け表示以外の通常ログに保存先・本文・写真IDを出さない。
