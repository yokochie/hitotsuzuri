# U2 本人の実機確認手順

## 起動条件

本人環境の読取結果はmacOS 27.2（26B123）・Xcode 27.2。対応先macOS 27、Swift 6、既存Sandboxとad-hoc署名を継続する。Xcodeで`Hitotsuzuri.xcodeproj`を開き、scheme `Hitotsuzuri`、実行先`My Mac`、Debugで起動する。通常起動には`--article-test-fixture`や`--ui-test-fixture`を付けない。本人の共有scheme変更は保持する。

OS認証画面が出た場合は本人が内容を確認して操作する。自動試験のために認証設定・TCC・キーボード設定を変更する手順は含めない。

## 下書きと撮影情報

1. 検証用アルバムの4枚を順番に選び、選択を確定する。「記事を開く」と「記事」メニューの入口で同じ下書きを開けることを確認する。
2. 新規記事ではアルバム名の絶対末尾がASCIIの`@YYMMDD`ならタイトル候補からその部分を除く。実在する日付だけを未確認の日付候補にする。例えば`散歩@261104`はタイトル`散歩`・2026年11月4日の候補、`散歩@260230`はタイトル`散歩`・日付なしとなり説明が出る。本文は空欄から始まる。保存済み記事を開く際にこれらの初期値で上書きしない。
3. タイトル、導入文、写真1〜4の文章、締めの文章、場所・機材・フィルム・人物名を編集する。年月日を確認・変更・削除する。部分入力や存在しない日付では入力が残り、理由が表示され、以前の有効日付で保存・プレビューされないことを確認する。
4. Command+Sまたは「保存」で手動保存する。保存中の追加入力が成功時に消えず、未保存表示が残ることを確認する。保存結果が不明の場合は照合が必要という表示を確認する。障害を実データの破損で意図的に再現しない。
5. 再起動し、現在の選択または「保存した下書きを開く」から再開する。同じ4枚を同じ順序で別の選択として再確定した場合は、候補から既存記事を選び、文章が引き継がれることを確認する。複数候補は表示内容を確認して本人が選ぶ。
6. 未保存のまま写真選択へ戻る・別記事へ切り替える・ウィンドウを閉じる・アプリを終了する各操作で、保存・破棄・編集継続を確認する。Escapeは編集継続。保存失敗や切替先の読込失敗では元の入力が残ることを確認する。候補シートと未保存確認が重なって操作不能にならないことも確認する。

## 表示・キーボード

1. 編集とプレビューを切り替える。プレビューは現在の入力を使い、編集へ戻ると直前の欄が見えることを確認する。投影中に入力を変更した場合は古い結果を表示せず、再表示の案内が出る。
2. ウィンドウを最小640×560pt付近から広げ、960ptの前後で写真とフォームの配置が切り替わっても入力が変わらないことを確認する。自動試験では640/959/960/961/1200ptを対象にする。
3. 長いタイトル・各本文、日本語・絵文字・結合文字・改行を入力し、折返しとスクロールで内容・保存操作へ到達できることを確認する。ベンチマークのタイトル200文字・本文各10000文字は入力上限ではない。
4. Tab/Shift+Tabで本文・日付・撮影情報・主要操作へ移り、Returnによる本文の改行とCommand+Sによる保存を区別できることを確認する。既存写真選択画面のキー操作も確認する。VoiceOverの追加確認は本人指定により対象外。
5. ローカルに取得できない写真があっても番号と状態が表示され、番号別に再試行でき、文章の保存・再開は継続できることを確認する。画像取得のために通信を要求せず、写真ライブラリを変更しない。

## 出力との境界

U2では本文コピーと4枚一式のOS出力は未接続であり、利用できない旨を表示する。これらの完成は`u3-article-export`。既存の「画像1枚の検証出力」は別操作として保持する。実写真の現在編集・向き・色・位置情報除去、Sandboxの保存先、一式出力とnoteへの手動受渡しは、該当Unitと本人の実機確認で扱う。合成fixtureの成功で確認済みとしない。

## 自動試験と確認状況

- U2機能限定: `bash scripts/verify-draft-experience.sh --functional`。
- UI限定: `bash scripts/verify-draft-experience.sh ArticleDraftUITests`。
- 製品全体の正式機能確認: `bash scripts/verify-native.sh --functional`。全製品の加重行カバレッジ80%以上を判定する。
- 性能を再現する場合のみ、本人Macで `bash scripts/verify-native.sh --performance`。CIでは実行しない。成功済みの今回の測定を本人確認のためだけに繰り返す必要はない。

この手順の本人確認は未実施。自動確認は、本人MacでCore性能5件とUI性能4件が成功し、最終CI41945323042では主機能426件と別smoke2件が成功、全製品行カバレッジ4207/4673=90.03%を確認した。実行結果は`tdd-evidence.md`と`ci-evidence.md`、集計は`code-summary.md`を参照する。独立レビューとUnit完了確認は別に行い、自動成功を実写真・Sandbox・note・最小高さ等の本人確認へ置き換えない。

## 戻し方

以前のビルドへ戻す前にアプリを終了し、必要な下書きと出力を保管する。写真ライブラリ・既存選択・完成出力を削除しない。U2は既存の記事保存schemaVersion 1を維持するが、新しい版や破損を検出したファイルを手動で上書きしない。ブランチの統合や公開配布が済んだものとは扱わない。
