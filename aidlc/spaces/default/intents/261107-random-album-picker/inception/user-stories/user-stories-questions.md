# ユーザーストーリー作成計画

本人のMacで記事用の写真を選ぶ利用者を1人のペルソナとして扱う。フォルダで候補を絞った後、写真を選び始めるアルバムを決める場面を扱う。承認済みの機能要件を必須とし、INVESTの観点で具体的な受け入れ条件に分ける。

## Q1. この利用者像で、どの粒度にまとめますか？

- A. 抽選から結果表示までを1本にまとめ、切り替え確認などを受け入れ条件に分ける。
- B. 抽選・切り替え確認・狭幅での結果表示を操作別の3本に分ける。
- X. Other (please specify)

[Answer]: B. 抽選・切り替え確認・狭幅での結果表示を操作別の3本に分ける。
