# 受け入れ条件と実装の対応

今回のexpress計画では独立した作業単位がない。全10件の対応は[実装の追跡表](../code-generation/traceability.json)に記録した。

| ストーリー | 検証 |
| --- | --- |
| US1.1 一覧から抽選 | Coreで候補範囲、0件・1件、同じアルバムを検証。ボタン操作はUI試験。 |
| US1.2 写真選択の保護 | Coreで確認の要否と古い抽選の拒否を検証。承諾と取消の操作はUI試験。 |
| US1.3 狭いウィンドウ | 当選後の画面と選択行はUI試験。 |
