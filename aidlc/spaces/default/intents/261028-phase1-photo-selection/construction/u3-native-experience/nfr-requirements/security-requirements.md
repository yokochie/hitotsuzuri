# U3 保護と表示整合

根拠: [機能仕様](../functional-design/functional-spec.md)、[規則](../functional-design/rules.md)、[要件](../../../inception/requirements-analysis/requirements.md)、[契約](../../../inception/contract-design/contract-summary.md)。[CI省略](../../../change-decisions/2026-10-31-local-verification.md)を適用し統合前ローカル検証を維持する。未測定を合格としない。

## 保護条件

| ID | 条件 | 検証 |
|---|---|---|
| NFR3.31 | 写真ライブラリ変更なし、画像取得通信なし、写真本体の恒久保存/外部送信なし | 境界と呼出しのコード確認、取得不可時の動作 |
| NFR3.32 | 保存置換の実成功と確定の写し/保存状態を一致させ、完了直後の認可変化・呼出し取消で成功を保存失敗へ変えない | 遅延保存Fakeで権限喪失/取消を競合、正常完了と実書込失敗を別検証 |
| NFR3.33 | 破損・未知版の原本保護、明示確定時の検証済み破損退避、symlink/過大拒否を維持 | U1/U2回帰。UIから直接書込しない |
| NFR5.31 | 通常診断は最小失敗分類のみ。性能計測は本人の測定時に集計値だけ扱い、ID・名称・画像・原本bytesを出力しない | 計測出力/通常ログ確認 |

## 適用範囲

個人用ローカルアプリの表示単位。認証基盤・クラウド・遠隔監視を追加しない。画像/参照再検証は認可後だけ行う。保存開始前の認可検証と、成功したローカル保存の結果反映を区別する。UIで権限不足を隠して成功表示だけにしない。
