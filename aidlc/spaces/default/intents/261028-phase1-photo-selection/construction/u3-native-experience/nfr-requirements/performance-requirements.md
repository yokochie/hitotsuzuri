# U3 性能と操作支援

根拠: [機能仕様](../functional-design/functional-spec.md)、[規則](../functional-design/rules.md)、[要件](../../../inception/requirements-analysis/requirements.md)、[契約](../../../inception/contract-design/contract-summary.md)。[CI省略](../../../change-decisions/2026-10-31-local-verification.md)を適用し統合前ローカル検証を維持する。未測定を合格としない。

## 測定対象

| ID | 条件と判定 | 検証 |
|---|---|---|
| NFR2.31 | 本人Mac、ローカル画像取得済み100枚以上、選択/解除30回以上の95%以上が入力イベント→実画面反映200ms以内 | 実入力と描画の時刻対応。状態更新時間だけで代用しない |
| NFR2.32 | 先頭末尾10往復後、不要要求0が15秒以内、必要集合外の保持が増え続けない | 各往復の必要数、保持数、要求数、bytesを比較 |
| NFR2.33 | 全生存画像と予約256MiB以下、最大8要求（表示4/検証4）、画像最大512物理pixel | Fakeの上限/取消/外部参照試験と実測 |
| NFR2.34 | 各画像と4枚全体15秒の絶対期限、待機列込み、通信false | 注入時計境界と実画像不可確認。認可ダイアログ/書込時間は対象外 |
| NFR4.31 | 許可→複数フォルダ→アルバム→写真→確定/再試行をキーボードのみで完了 | 矢印、Space、Tab、可視フォーカス、領域退出と復帰 |
| NFR4.32 | VoiceOverで名称・展開・選択順・枚数・保存結果・復元と理由を確認 | 取得不可も理由へ到達、色のみに依存しない |
| NFR4.33 | 1280×800pt、640×560pt、820pt境界で全操作に到達 | 4枠と操作を保持、長名全名、領域/フォーカスID保持 |
| NFR4.34 | 通常文字4.5:1、大文字/操作要素3:1以上 | ライト/ダークとコントラスト設定で測定 |

## 条件

画像読込中も無関係な操作を止めず、復元/検証/保存の編集禁止だけを維持する。レイアウトの実装方式と計測器はNFR Designで確定する。CPU・メモリ使用率だけでは画面反映の達成としない。
