# 性能の検証

## 判定と実機

100枚以上の実アルバムで画像取得後に選択/解除30回以上を記録し、95%以上が入力イベント→画面反映200ms以内。10往復で保持が増え続けず、最終端点後15秒以内に不要要求0。詳細は[U3本人手順](../u3-native-experience/code-generation/manual-verification.md)。画面採取は本人の許可後だけ、画像を恒久保存しない。

## 失敗の再現

公開NativeMeasurement/FrameMeasurementに対し空の同じ選択位置を30回recordし、フレームを対応させるとpassed=trueとなる。選択変化がないため有効な30操作ではなく不具合。再現の実コマンドと出力はtest-results.mdに記録する。修正前に性能合格を表示しない。単体判定成功を実画面性能合格としない。
