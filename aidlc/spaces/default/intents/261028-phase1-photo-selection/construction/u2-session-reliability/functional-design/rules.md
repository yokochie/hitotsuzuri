| ID | 要旨 |
|---|---|
| BR2.1 | 許可を確認してから参照と画像を検証し、拒否・制限・喪失時は権限案内を優先して保存原本を保護する。 |
| BR2.2 | 保存なし・正常・破損・未対応版・I/O失敗を区別し、原本を勝手に上書きしない。設定と確定を独立に評価する。 |
| BR2.3 | 有効フォルダを復元したうえで対象アルバムと重複なし4枚の存在・所属・ローカル画像を検証する。全成功なら選択順と確定状態を復元する。 |
| BR2.4 | 1枚でも欠損・取得不可、アルバム削除・対象外なら写真選択全体をクリアし、有効な対象フォルダだけを残す。保存原本は変更しない。 |
| BR2.5 | 復元中の編集を受け付けず、世代・操作IDの異なる古い結果を不採用にする。結果が確定するまで保存済みと表示しない。 |
| BR2.6 | 編集と最後の確定を分離し、新しい保存成功まで旧確定を保持する。終了時の編集は保存せず、アルバム・フォルダ切替はFR5の規則を維持する。 |
| BR2.7 | 固定した編集の権限・現在参照・所属・画像を毎回再検証する。保存中は入力と重複確定を拒否し、失敗では旧確定と編集を保持する。 |
| BR2.8 | 本人が改めて確定した場合に限り、破損原本を安全に退避してから新内容を置換する。退避失敗・置換失敗は成功とせず原本を保護する。未対応版は書込を拒否する。 |
| BR2.9 | 自動追従と手動更新は追加しない。無効参照や画像準備は再起動案内、書込失敗は本人の再試行とし、原因不明を断定しない。 |
| BR2.10 | 状態文で読込・復元・空・失敗・成功を分け、TDDと80%以上の統合前ローカル検証を記録する。実機確認は自動検証と区別する。 |
