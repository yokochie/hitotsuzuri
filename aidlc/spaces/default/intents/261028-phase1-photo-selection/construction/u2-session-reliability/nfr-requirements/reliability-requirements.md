# U2 reliability-requirements

根拠: [機能仕様](../functional-design/functional-spec.md)、[ルール](../functional-design/rules.md)、[要件](../../../inception/requirements-analysis/requirements.md)、[契約](../../../inception/contract-design/contract-summary.md)、[CI省略](../../../change-decisions/2026-10-31-local-verification.md)。本書は要求であり動作確認結果ではない。

| ID | 条件 | 検証 |
|---|---|---|
| NFR3.25 | 保存後の新セッションでは全参照と4画像が有効なら順序/日時/確定状態を復元し、一部欠損では全写真クリアと有効フォルダ保持 | 正常/欠損1枚/所属変更/アルバム削除/対象外/画像不可を結合テスト |
| NFR3.26 | 退避の作成・内容検証後にだけ新確定を原子的置換。退避/置換の失敗では成功表示せず旧原本と編集を保持 | 各I/O段階の失敗注入と強制中断相当の境界テスト |
| NFR3.27 | 再試行は本人操作で毎回再検証し、結果未確定の書込みを二重開始しない。編集は終了時保存しない | 失敗/重複/遅延/終了再開のテスト |
| NFR4.21 | 権限・復元中・復元成功・欠損・破損・未知版・書込失敗の案内と次の操作を区別 | 状態投影を自動検証。最終VoiceOver/キーボード全経路はU3 |

既決の条件を維持するため、追加の製品質問はない。具体的な実行境界・退避方式・テスト構成を次の技術設計で決める。本人のMacだけを対象とし、クラウドのSLA・水平拡張・遠隔監視は非該当。復元UIの完成条件をU3の最終操作支援と混同しない。
