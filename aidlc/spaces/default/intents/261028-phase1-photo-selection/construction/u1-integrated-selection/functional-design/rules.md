| ID | 対象 | 要旨 |
|---|---|---|
| BR1.1 | 認可 | 許可されている場合だけライブラリ取得へ進む。未決定は本人操作で要求し、拒否・制限・未対応は案内する。 |
| BR1.2 | 階層探索 | 選択フォルダから子フォルダを辿り、訪問済みフォルダIDとアルバムIDを記録して重複と循環を除外する。対象外は含めない。 |
| BR1.3 | 写真一覧 | 写真だけを抽出して元の相対順序を保つ。同名異IDは別物。表示用画像が取得できる写真は形式によらず対象。 |
| BR1.4 | 画像要求 | 通信を禁止する。現世代の現要求に一致する画像だけ採用し、不要要求を取り消す。取得中・取得不可・失敗は追加不可。原因不明を断定しない。 |
| BR1.5 | 編集選択 | 選択済みなら解除して残りを詰める。未選択で取得可能かつ4枚未満なら末尾追加。その他は変更しない。 |
| BR1.6 | 確定可能性 | 対象内のアルバムと重複なし取得可能4枚があり、検証・保存中でないときだけ確定可能。 |
| BR1.7 | 切替 | 同一アルバムなら維持し、別アルバムなら編集写真をクリア。フォルダ変更後に現アルバムが対象内なら維持し、対象外ならアルバムと編集写真をクリア。 |
| BR1.8 | 確定処理 | 開始時の編集内容を固定し、編集・設定変更・重複確定を拒否する。入力を後で実行する待ち行列は作らない。 |
| BR1.9 | 参照 | 現在の権限・対象フォルダ配下のアルバム・4枚の存在と所属・ローカル画像取得可否を再検証する。再取得結果を選択順に戻す。 |
| BR1.10 | 保存 | 固定内容の識別子・順序・日時・アルバムを専用領域へ保存し、要求IDと内容の一致する完了結果後だけ成功を公開する。画像は恒久複製しない。 |
| BR1.11 | 永続化保護 | 設定と確定は別レコード。書込を直列化して旧正常内容を保持し、失敗は明示して本人の再試行を待つ。再試行前に再検証する。 |
| BR1.12 | 外部変更 | 起動中の自動追従・手動更新を追加しない。参照無効化は確定時に検知し、再起動して読み直す案内を出す。 |
| BR1.13 | 編集と確定 | 編集中の選択を保存しない。新たな保存成功まで最後の確定を保持し、編集が違う場合は未保存とする。復元の完成はU2。 |
| BR1.14 | 検証 | TDD、80%以上の行カバレッジ、統合前CIと日本語手順を記録する。許可・実アルバム順・画像アクセスは本人の実機確認として区別する。 |
