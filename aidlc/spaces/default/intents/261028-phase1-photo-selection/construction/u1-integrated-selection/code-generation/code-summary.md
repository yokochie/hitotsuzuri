# U1 実装要約

## 実装した範囲

作業ブランチcodex/u1-integrated-selection。Xcodeのアプリ/Core/U1テスト構成、PhotoKitの認可・階層参照・再帰探索とID重複排除、アルバム順の写真抽出、通信なし画像、4枚選択と解除番号、確定前の参照・画像再検証、版付きJSON保存、失敗時の編集と旧確定の保持を実装した。画面は複数フォルダ・アルバム・写真の3領域と常設4枠、枚数と確定操作を備える。

全変更ファイルは[source-manifest.json](source-manifest.json)。製品はリポジトリルートに置き、記録ディレクトリへアプリコードを置かない。[CI省略](../../../change-decisions/2026-10-31-local-verification.md)に従いローカル検証を行う。コミット・統合はまだ行っていない。

## 判断と計画との差分

- PickerContent.swiftをCoreへ分けてネイティブ画面をテスト可能にし、アプリ側PickerViewは薄い接続とした。所有責務は変更しない。
- テストは目安35〜45件から60件へ増やした。品質条件と未検証分岐・画像寿命・絶対期限・原本保護の回帰確認を補うため。
- 日時を保存のISO8601秒精度へ合わせてモデル生成時に揃える。
- 構文が正常でも4枚条件を満たさない旧JSONを上書きする不具合を結合テストで検出し修正した。
- ImageRendererでHSplitViewの検証中にクラッシュしたため、テストをNSHostingViewのレイアウトへ変更した。製品機能を削除していない。
- ブートストラップ専用の定数テストはランナー動作確認後に削除。最終49件には含めない。
- 画像予算はキャッシュだけでなく返却画像と描画プロバイダが保持する不変ストレージも生存中に計上する。小予算・同一写真再検証・CGImageだけの保持を検証した。
- 単調時計の絶対期限を受付時に保存し、キュー開始・終端応答採用で再照合する。期限ちょうど・MainActor遅延・4枚共通期限を検証した。
- 空IDなど意味上壊れた設定JSONも読込時に拒否し、設定変更で旧原本を上書きしない。フォルダ除外後は古い保存成功案内を消し、旧確定内容を保持する。

## 未実施・限界

実写真の読み取り、OSの許可/拒否、Sandboxと署名での本人のアプリ起動、写真アプリの手動順との一致は未確認。自動テストではFakeと合成画像・専用保存先を使用した。

scripts/verify-u1.shは作成済みだが、最終Construction Verification Commandとしての承認・実行はまだ行っていない。通常のTDD用テスト実行とは区別する。

復元の全経路はU2、最終レイアウト・狭幅・VoiceOver・100枚以上の表示性能と資源実測はU3。これらをU1で合格済みとしない。iOS Simulator旧版の環境警告は出ているがmacOSビルド・テストは成功した。
