# U1 Xcodeでの起動と実機確認

## 起動

1. Finderでリポジトリ内のHitotsuzuri.xcodeprojを開く。
2. Xcode上部のschemeをHitotsuzuri、実行先をMy Macにする。
3. Run（三角ボタン）を押す。ローカル署名とSandboxの実際の起動可否を確認する。署名エラーが出た場合は文面を共有し、勝手に証明書購入や権限リセットを行わない。
4. 「ひとつづり」の写真の利用目的を読み、許可操作を行う。OSが示す権限名は読み書きでも、アプリは写真ライブラリを変更しない。
5. フォルダをCommandキーで複数選び、アルバムを1つ選んで写真を表示する。
6. ローカルで取得可能な写真を4枚選び、下部の画像・番号・枚数を確認して確定する。

## 確認欄

以下はすべて未確認。実行したものだけ結果を記入する。

| 項目 | 操作と期待 | 結果 |
|---|---|---|
| 起動と名前 | Xcodeから起動し「ひとつづり」が表示される | 未確認 |
| 未許可・拒否 | 許可前に取得せず、拒否時は案内する。OS設定の変更は本人が行う | 未確認 |
| 複数/深いフォルダ | 2フォルダ以上、3階層以上を選び配下アルバムが現れる | 未確認 |
| 重複 | 親子を同時選択しても同じアルバムを重複表示しない | 未確認 |
| 写真の並び | 写真アプリで手動並べ替えした順と比較。一致しなければ実装を完了とせず報告 | 未確認 |
| 写真分類 | 動画が除かれ、表示用画像が得られるLive Photos/RAWは静止画として扱う | 未確認 |
| 取得不可 | ローカルにない等の画像は選択不可となり案内する。通信要求へ切り替えない | 未確認 |
| 4枚と順序 | A,B,C,Dを選び、5枚目は追加不可。B解除でA,C,D、B再選択でA,C,D,B | 未確認 |
| 切替 | 別アルバムで編集写真クリア。同じアルバム再選択は保持 | 未確認 |

再起動復元の完成はU2の範囲。U1で復元しないことを今回の機能完成と混同しない。写真アプリ側の変更の読直しは再起動で行う。

## 結果の伝え方

確認した項目、成功/失敗、表示された案内を伝える。写真ID・個人写真・アルバム名の公開は不要。画面が必要な場合は個人情報を隠す。未確認項目は未確認のまま残す。
