# アルバム一覧へのTab入場と上下キー

本人905a320cは「アルバムが枠だけ選択されてしまい、上下に動かすことができませんでした」と報告した。先頭選択の自動回帰は通過していたが、Tab入場直後の上下キーによる行移動と写真表示の追随が試験に不足していた。実機の操作成立はNot Met、197件成功と区別する。

本人の不具合報告に対応してU3だけを再開。先頭・中間・末尾への実上下キー操作、再入場・逆Tab・狭幅での行操作を回帰として計画する。既存の4枚規則、写真のfocusのみ、既存選択/編集保護、既知子折畳み保留とU1/U2は維持する。小規模〜中規模（20〜45分、追加費用0、native焦点/選択/アクセシビリティの回帰リスク）。計画を本人確認後に実装する。自律失敗ループの上限を独断で増やす扱いにはしない。
