# ひとつづり — 画面概略

## HTMLによる確認

[操作できるHTMLモック](mockup.html)で、3領域の配置と4枚選択を確認できる。写真は図形による架空の画像。フォルダの複数選択、アルバム切替、4枚制限、選択解除による番号の振り直し、保存成功の表示を試せる。実ライブラリへのアクセスや永続保存は行わない。以下の状態一覧はHTMLで未再現の許可・復元・失敗状態も含む補足仕様として残す。

## 入力と位置づけ

[目的の文書](../intent-capture/intent-statement.md)、[範囲定義](../scope-definition/scope-document.md)、[作業一覧](../scope-definition/intent-backlog.md)、[確認済み回答](rough-mockups-questions.md)を入力とする。これは配置と状態の概略であり、寸法・配色・詳細な挙動はInceptionで具体化する。

## 情報の構成

主画面は左からフォルダ階層、アルバム名一覧、写真グリッドの3領域。右領域の下部に選択順の4枠、選択枚数、確定ボタンを固定する。フォルダはCommandキー等による行の複数選択とし、階層を開く操作と選択を分ける。写真の選択操作はクリックまたはキーボード操作とし、選択順の番号と選択状態を読み上げで確認できるようにする。

検索、アルバム一覧の写真枚数・代表画像、手動更新は置かない。写真グリッドのサムネイルは表示する。ウィンドウ幅が不足する場合は一覧領域を畳み、明示された領域切替からフォルダ・アルバムへ戻れる案とする。最低幅・切替条件・フォーカス復帰の詳細はInceptionで決定する。

## W-01 初回のアクセス案内

```text
+------------------------------------------------------+
| ひとつづり                                           |
| アルバムから写真を4枚選び、選択内容を保存します。      |
| 写真ライブラリは参照に使い、内容は変更しません。      |
|                                                      |
|              [ 写真へのアクセスを許可 ]              |
+------------------------------------------------------+
```

主操作でOSの許可要求に進む。拒否・制限の場合は理由に応じた案内とシステム設定での確認方法を表示する。制限が設定変更だけで解除できるとは断定しない。

アクセシビリティ: 主見出しは「ひとつづり」（h1相当）、mainに説明とボタンを配置。キーボードの入口は許可ボタン。説明とボタン名をVoiceOverで確認できる。

## W-02 フォルダ・アルバム・写真の選択

```text
+----------------+------------------+-----------------------------+
| フォルダ       | アルバム         | 写真を4枚選択               |
|                |                  | 選択アルバム名              |
| v 撮影記録     | アルバム A       |                             |
|   v 2026       | アルバム B       | [写真  1] [写真   ]         |
|     人物       |                  | [写真   ] [写真  2]         |
|     風景       |                  | [写真   ] [写真   ]         |
| > アーカイブ   |                  |                             |
|                |                  |-----------------------------|
| Cmdで複数選択  |                  | [1][2][ ][ ]  2 / 4枚        |
|                |                  | [ 選択を確定（無効） ]      |
+----------------+------------------+-----------------------------+
```

行選択の強調と写真の選択番号は色だけに依存させない。図の番号は写真の選択順を表す。フォルダ名とアルバム名は仮の表示例であり、実際の本人のデータを示さない。長い名前には切り詰めだけに依存せず、全名を確認する手段を詳細設計で用意する。

下部の4枠はグリッドのスクロール中も表示し、選んだ順に小さな写真を置く。未選択枠は空枠として区別する。4枚未満では確定を無効にし、理由を選択枚数で示す。4枚のときのみ確定に進める。5枚目は追加しない。

アクセシビリティ: ウィンドウの主見出しはh1相当、各領域名はh2相当。nav相当のフォルダとアルバム、main相当の写真、footer相当の選択欄を区別する。キーボードの入口はフォルダ一覧で、各領域へ移動可能にする。各写真に識別可能なラベルと未選択・選択順を付ける。ここでのh1等は意味上の階層であり、HTML/ARIA実装の指定ではない。

## W-03 保存中・保存成功・保存失敗

| 状態 | 選択欄付近の表示 | 操作の方向 |
|---|---|---|
| 4枚選択済み | 4枠・4 / 4枚・有効な「選択を確定」 | 確定時に参照の有効性を確認する |
| 検証・保存中 | 「確認・保存しています」 | 重複した確定操作を防ぐ。選択変更を許すかは詳細要件で決める |
| 保存成功 | 「選択を保存しました」、対象アルバム名、順序付き4枚 | 保存が完了したことを明示する |
| 参照が無効 | 「写真またはアルバムを確認できません。選び直してください」等 | 保存成功にせず、復旧手順を示す。変更読込みは再起動 |
| 保存失敗 | 「保存できませんでした」、原因に応じた案内 | 選択が保存済みと誤認されないようにする。再試行等の詳細は要件化 |

アクセシビリティ: W-02と同じ見出し・領域を保持し、footer相当の状態文を読み上げで確認できる。キーボードの入口は確定ボタン。処理完了時に不必要に別領域へフォーカスを飛ばさない方針とする。

## W-04 再起動・復元

| 状態 | 表示 |
|---|---|
| 復元中 | 「前回の選択を確認しています」 |
| 有効な復元 | 対象フォルダ、アルバム、順序付き4枠と保存済み状態 |
| 無効な参照がある | 「前回の選択の一部を確認できません。選び直してください」等。確定済み扱いにしない |
| 保存データなし | フォルダ選択を促す通常の空状態 |
| 許可がない | ライブラリ取得や復元を進めずW-01の拒否・制限案内へ |

一部復元時に残りを何枚保持するか、最後の確定選択と編集中選択の区別はInceptionで決める。画面案では未決定の挙動を確定させない。

アクセシビリティ: 主見出しh1相当、mainに復元状態の説明。復元中の変化を確認できるようにし、完了後のキーボード入口は必要な選び直しを行う領域とする。詳細なフォーカス規則は後で決定する。

## W-05 読み込み・空・取得失敗・部分状態

| 条件 | 該当領域の表示・案内 |
|---|---|
| フォルダ未選択 | 「対象フォルダを選択してください」 |
| 配下にアルバムなし | 「アルバムが見つかりません」 |
| アルバム未選択 | 「アルバムを選択してください」 |
| 写真なし | 「このアルバムには写真がありません」 |
| 読み込み中 | 該当領域に進行表示。全画面を無説明で空白にしない |
| 画像取得不可 | 写真枠に取得不可を文字・記号で表示。通信は要求しない。選択・確定可否はInceptionで決定 |
| 4枚未満の写真 | 表示できる写真は表示し、4枚が揃わない限り確定は無効 |
| 長い名称 | 領域を崩さず、全名を確認する手段を用意する |

アクセシビリティ: W-02の見出し階層と領域を保持し、状態文を該当領域内に置く。キーボードの入口は次に操作できる一覧またはボタン。色だけで読み込み失敗や選択状態を示さない。

## 今回の画面に置かないもの

検索、アルバム一覧の写真枚数・代表画像、自動更新の切替、手動更新ボタン、note・動画・クラウド・履歴等の後続機能は配置しない。

## Inceptionで具体化すること

ウィンドウの最小サイズと領域の折り畳み、キーボードによる複数選択手順、写真ラベルとフォーカス移動、画像取得不可時の選択・確定可否、選択解除後の順序、アルバム変更時の選択、保存中の編集、成功後の編集と復元時の部分欠損。
