# 操作支援・画面検証チェックリスト

入力: [画面概略](../../ideation/rough-mockups/wireframes.md)、[利用フロー](../../ideation/rough-mockups/user-flow.md)、[ストーリー](../user-stories/stories.md)、[要件](../requirements-analysis/requirements.md)、[開発規約](../practices-discovery/team-practices.md)、[確認回答](refined-mockups-questions.md)。

各項目は設計上の確認計画。未チェックを合格と扱わない。HTMLの確認結果とネイティブ版の本人確認結果を区別する。

## キーボード・フォーカス

- [ ] 許可・フォルダ展開・複数選択・アルバム選択・写真選択/解除・確定・再試行をキーボードだけで完了できる。
- [ ] フォーカスが見え、グリッドからTabで退出できる。
- [ ] 領域切替と一覧への復帰で選択を維持し、適切な操作位置に戻れる。
- [ ] 保存中に選択変更できず、終了後にフォーカスを不必要に奪わない。

## VoiceOver・文言

- [ ] フォルダの名前・選択・展開状態、アルバム名・選択状態を確認できる。
- [ ] 写真を識別でき、選択順1〜4と枚数を確認できる。
- [ ] 読み込み・取得不可・保存成功・未保存変更・失敗・復元欠損を確認できる。
- [ ] 確定不可の理由と再試行・再起動の手段が分かる。
- [ ] 長い名称の全名を確認できる。原因不明を断定する文言がない。

## 視覚・幅

- [ ] 通常文字4.5:1、大きい文字とUI要素3:1のコントラストを測定する。
- [ ] 色以外の番号・枠・文言で状態を区別できる。
- [ ] 下部4枠はグリッドと対応する画像であり、選択順も一致する。
- [ ] 1280×800ptと最小640×560ptの案で操作が画面外へ失われない。
- [ ] 820pt付近の切替で写真と選択欄が見え、フォルダ・アルバムへ戻れる。
- [ ] ネイティブのダーク表示・コントラスト設定で確認する。

## シナリオ

- [ ] 通常0〜4枚・5枚目禁止・解除後番号振り直し。
- [ ] 未許可・拒否・制限・読み込み・空・取得不可。
- [ ] 保存中の操作禁止、保存失敗の再試行、参照無効の再起動案内。
- [ ] 保存後編集の未保存表示、復元成功、1枚欠損時の全選択クリア。

## 結果の記録

確認日、OS・ウィンドウサイズ、使用した入力方法/VoiceOver、対応するUS/AC、実際の結果、未確認理由を記録する。正式なアクセシビリティ認証を取得したという意味ではない。
