# CI計測の設計

`../nfr-requirements/observability-requirements.md`と`performance-design.md`を参照。
- 比較表はPR更新イベントと対応するhead SHA、Actions run ID/attempt、更新・job開始/完了時刻、結果、環境、試験集合、キャッシュ条件を記録する。PR更新時刻はPR側のイベント証拠と照合し、Actions作成時刻は参考値として区別する。ジョブ間待ち・処理時間を分ける。
- 変更前は過去の成功記録を3件以上。変更後は同等条件の成功実行3回以上。取得できる最初の失敗時刻も同じ起点から記録する。標本選定条件、除外理由、中央値と全標本を残し、不足・比較不能は達成判定を保留する。
- 既存のActionsログとxcresultを照合する。試験の準備・待ちが内訳で分かれない箇所は、改善候補の検証時に必要な区間だけ計測する。新規外部サービスの導入は設計範囲外。
