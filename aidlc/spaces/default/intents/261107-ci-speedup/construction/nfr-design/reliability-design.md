# CIの正確性と復旧設計

`../nfr-requirements/reliability-requirements.md`を設計へ反映する。
- Coreの失敗はその段階で止め、必須smokeと全機能の選択・失敗検出・結果検査を保持する。変更したUIケースは同じケースID、操作、観測結果を対照し、条件未達時に失敗することを確認する。
- 80%の全製品カバレッジは現行の機能bundleから検査する。実行結果が欠損・不一致・部分的なら成功にしない。準備領域は各ケースの所有確認を経て回収する。
- 再実行は同じ対象の別attemptとして記録する。取消や時間切れの結果を流用しない。キャッシュなしの経路でも実行する。
- 問題時は変更したCI設定・スクリプト・テスト補助を該当差分単位で戻し、必須チェックの再実行で復旧を確認する。
