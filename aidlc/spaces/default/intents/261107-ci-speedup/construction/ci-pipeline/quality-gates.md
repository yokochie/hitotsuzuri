# CIの品質・性能判定

| 項目 | 合格条件 |
|---|---|
| 試験選択 | runner契約テストとCore全対象が合格 |
| macOS UI | 必須smokeと機能回帰が実行され、選択された試験の実行証跡がある |
| 保存確認 | シートまたはダイアログが表示され、呼び出し側のボタン操作と検証を通過 |
| 回収 | ケース固有のrootの回収成功表示を確認 |
| カバレッジ | 既存の全製品行カバレッジ80%以上 |
| 所要時間 | 比較可能な過去・変更後の成功記録各3件以上で、PR更新から全必須チェック完了までの中央値が30%以上短縮 |

同じPR更新の初回attemptだけを成功標本候補とする。再実行、失敗、取消は別記する。変更前は過去の記録だけを用いる。条件が揃わない場合は判定保留とし、待ち・実行・失敗検出時間は取得できた範囲で記録する。
