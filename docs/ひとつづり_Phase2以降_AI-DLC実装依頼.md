# ひとつづり — Phase 2以降のAI-DLC実装依頼

設計書を`docs/ひとつづり_Phase2以降_設計.md`へ配置するか添付し、以下を実装用チャットに渡してください。

## Phase 2開始用の依頼文

「ひとつづり（Hitotsuzuri）」のPhase 1が完了しました。既存のAI-DLCワークフローを引き継ぎ、Phase 2のnote記事作成支援を進めてください。

入力資料：`docs/ひとつづり_Phase2以降_設計.md`（添付の場合は添付ファイル）。Phase 1の設計書、既存コード、AI-DLC成果物、テスト結果も参照してください。

1. 実コードと既存のAI-DLC記録を読み、Phase 1の現在地、未解決事項、モデル、保存形式、対応OSを確認してください。
2. 導入済みAI-DLCの版と規約を優先し、未導入の場合は https://github.com/awslabs/aidlc-workflows を参照して適用方法を確認してください。
3. 後続設計書は提案として扱い、実コードと照合してください。Phase 1を再実装せず、既存データの互換性を保つ方針を示してください。
4. Phase 2のInceptionとして、要件、画面、モデル差分、保存形式移行、実装単位、受け入れ条件、テスト方法を整理してください。
5. 初期範囲は、下書き編集・保存、撮影日候補の抽出、画像4枚と記事Markdownの書き出し、本文コピー、Finder表示です。noteへの受け渡しは手動です。
6. 未確定事項には推奨案を提示してください。要件と計画を私が確認した後にConstructionへ進んでください。
7. 実装では写真の順序、現在の編集結果、iCloud取得、キャンセル、書き出し失敗、既存成果物の保護を確認してください。
8. 各実装単位で適切なビルドとテストを行い、手動確認が必要な項目を記録してください。成果物の本文は日本語にしてください。

Phase 3・4は将来の接続点として考慮しますが、今回は実装範囲に含めません。まず既存実装の照合とPhase 2のInceptionから開始してください。

## Phase 3へ進むときの追加依頼文

Phase 2の完了結果を確認し、後続設計書に従ってPhase 3のInceptionを開始してください。初期範囲はPhase 3A（4枚・無音・縦型MP4・プレビュー・保存）です。演出とBGMは別の実装単位にしてください。既存の画像取得基盤と制作モデルを再利用し、実画像による動画生成の技術検証を先に計画してください。要件と計画の確認後にConstructionへ進んでください。

## Phase 4へ進むときの追加依頼文

Phase 2・3の完了結果を確認し、後続設計書に従ってPhase 4のInceptionを開始してください。制作一覧、記事と動画の独立した状態管理、成果物履歴、未制作アルバム候補、週次ローカル通知を対象とします。書き出し完了と公開完了を区別し、入力変更時に成果物の再出力が必要か判定してください。アプリ終了中の写真走査や自動動画生成は初期範囲に含めません。要件と計画の確認後にConstructionへ進んでください。
